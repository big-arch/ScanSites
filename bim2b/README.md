## Кто это

**BIM2B («БИМ для бизнеса»)** — московская консалтинговая компания по внедрению ТИМ (BIM) у проектировщиков и девелоперов.

- Основатель — **Дмитрий Чубрик**. Внедряет Autodesk Revit с 2008 года, бренд BIM2B основал в 2015 году.
- Юрлицо ООО «BIM2B» зарегистрировано 20.04.2016. ОГРН 1167746398984, ИНН 7751020243.
- Компания разрабатывает **ADSK-шаблоны Revit**, бесплатные и самые распространённые корпоративные шаблоны в русскоязычной практике.

## Ключевые знания

### 1. ADSK-шаблоны Revit
- Шаблоны по разделам **АР, КЖ, КМ, ОВ, ВК, ТХ**, стадии П и РД.
- Шаблоны 2021+ используют **ФОП Autodesk**, файл общих параметров к BIM-стандарту Autodesk. Параметры имеют префикс `ADSK_`.
- Виды группируются в диспетчере проекта по параметру `ADSK_Назначение вида`.
- Листы заполняются через `Номер проекта` и `ADSK_Штамп Раздел проекта`.
- Для Revit 2021 и новее нужно руководство **manual2021.bim2b.ru**, а не старое manual.bim2b.ru.

### 2. Плагин BIM2B Template Tools
- Автоматизирует работу с ADSK-шаблонами. Среди инструментов: перемычки (подгоняет отметку и ширину по проёму) и «Квартирография» (заполняет ADSK-параметры для подсчёта квартир).
- Развивается только ветка **3.x**. Версия 2.1.4 доступна, но больше не поддерживается. Версия 3.0 под Revit 2022 вышла 04.02.2025.
- Лог ошибок: `C:\ProgramData\Autodesk\ApplicationPlugins\BIM2B TemplateTools.bundle`. В обращении указывайте версии плагина, Revit и Windows.

### 3. Нормативка ТИМ (как её подаёт BIM2B)
- **СП 333.1325800.2020** не разделяет стадии П и РД. Большую часть данных нужно вносить уже на стадии П (уровень проработки «B»).
- **IDS** (Information Delivery Specification, buildingSMART) — машиночитаемые требования к модели. ЦГЭ Санкт-Петербурга перевёл требования к ЦИМ в IDS.
- **CDE (ISO 19650)** — статусы контейнеров информации и коды пригодности. Новым статусам посвящён BIMdigest 187.
- Позиция автора: обязательный ТИМ вводят поэтапно по категориям объектов, а официальных разъяснений Минстроя по СП 333 и КСИ не хватает.

### 4. Тренды 2026 из BIMdigest (выпуски 176–201)
- **AI в BIM:** AI-программирование (191), «Вы всё ещё не программируете?» (198, новый портал Revit API и онлайн-редактор кода), AI для IDS как помощник BIM-менеджера (201), «AEC после AI» (176).
- **Revit 2027** (185). Плагины от производителей оборудования (186).
- **Цифровые двойники городов** (195): CityGML Хельсинки, VR Гамбурга.
- **Open BIM:** бесплатный BonsaiViewer для IFC (192).
